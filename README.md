# 三花小账本官网与隐私政策

这是三花小账本的独立静态官网仓库，用于公开展示应用介绍、隐私政策和第三方 SDK 清单。

正式网址：https://shichen886.github.io/maomao-jizhang-privacy/

## 内容

- `index.html`：应用官网首页
- `privacy.html`：隐私政策
- `sdk.html`：第三方 SDK 清单
- `styles.css`：统一响应式样式
- `assets/`：应用图标、猫猫角色和公开界面截图

网站不包含 Flutter 源码、数据库、签名文件、备份文件或用户数据，也不使用 Cookie、广告、统计、追踪脚本和外部字体。
