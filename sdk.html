第三方 SDK 与开源组件清单

以下清单依据当前 Flutter 依赖、Android Gradle 依赖和实际代码用途整理。普通算法与界面工具不会被夸大描述为个人信息收集 SDK。

更新日期：2026 年 8 月 1 日 对应应用版本：1.0.0 开发者：杜士辰
披露原则

当前版本没有广告、统计、推送营销、在线支付、云端 AI 或账号系统。

重点数据处理组件

Google ML Kit 中文文字识别
提供方
Google LLC；Flutter 桥接组件由 flutter-ml.dev 社区维护
使用目的
识别用户主动选择的账单图片和主动截取的当前账单画面
处理的数据
用户选择或主动截取的图片像素，以及从图片中识别出的文字
是否联网
三花小账本使用随 APK 打包的中文识别组件，Release 构建不授予应用互联网访问权限
是否上传内容
不由三花小账本上传，识别在设备内完成
官方说明
ML Kit Android 文字识别说明；Flutter 组件说明
sqflite 与 SQLite
提供方
tekartik.com 社区与 SQLite 项目
使用目的
在应用私有目录保存账本、账目、分类、共同分账、规则、设置和猫猫成长数据
处理的数据
用户输入或确认保存的本地结构化数据，以及用户主动设置的账本封面数据
是否联网
否
是否上传内容
否
官方说明
sqflite 组件说明；SQLite 项目说明
image_picker
提供方
Flutter 官方团队
使用目的
调用系统图片选择器，让用户主动选择需要识别的账单图片或需要设置的账本封面
处理的数据
用户明确选择的图片文件路径和图片内容；OCR 图片只用于当次识别，用户确认设置的封面会保存在本机
是否联网
否
是否上传内容
否
官方说明
image_picker 组件说明
file_picker 与 path_provider
提供方
miguelruivo.com 社区与 Flutter 官方团队
使用目的
通过系统文件选择器导入、导出备份，并定位应用私有文件目录
处理的数据
用户主动选择的备份文件、导出位置和应用内部路径
是否联网
组件本身不要求三花小账本联网。若用户选择第三方云盘位置，由对应系统文件提供方处理
是否上传内容
三花小账本不主动上传
官方说明
file_picker 组件说明；path_provider 组件说明
flutter_secure_storage、local_auth 与 cryptography
提供方
Flutter 社区与 dart.dev 认证发布者
使用目的
保存应用锁安全材料、派生 PIN 摘要，并调用系统生物识别验证
处理的数据
随机盐、PIN 派生摘要、应用锁开关和系统验证结果
是否联网
否
是否上传内容
否；应用不读取指纹或面容模板
官方说明
安全存储说明；生物识别组件说明；cryptography 说明

其他开源工具

应用还使用 Riverpod、go_router、fl_chart、intl、collection、crypto 和 path 等开源工具完成状态管理、页面导航、本地图表、日期格式化、集合处理、完整性校验和路径处理。这些工具不会因为被引入而自动收集或上传个人信息。

应用在接入新的广告、统计、云端服务或可能处理个人信息的第三方组件前，会先更新本清单与隐私政策，并按政策版本重新征求用户同意。
